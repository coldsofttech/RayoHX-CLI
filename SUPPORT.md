# Support

- **Start with the docs:** the [README](README.md) covers installing and using the command, and the [command line guide](docs/guides/cli.md) lists every option, setting and exit code.
- **Questions and ideas:** use [GitHub Discussions](../../discussions) if enabled, otherwise open an issue.
- **Bugs:** open an issue with the bug report form. Say your operating system and version, your Python version and how you installed it, and include the output of `rayohx --version`.
- **Security problems:** see [SECURITY.md](SECURITY.md).
